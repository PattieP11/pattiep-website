# pattiep.com

Pattie Philibosian Real Estate website.

## Owner's note
- Live at https://pattiep.com. Hosted free by GitHub Pages in Pattie's own GitHub account (PattieP11). The web address is Pattie's, registered at GoDaddy.
- To change words, reviews, the listing card or contact details: ask BOSS ("change X on my website"). Everything lives in content.json; BOSS edits it, runs `python3 build.py`, checks it and publishes.
- Contact form: messages go to Pattie's email (Web3Forms) and into GoHighLevel tagged "Website Contact" (through Pattie's Client Tools at client-tools-site-nu.vercel.app).
- To undo a change: ask BOSS "undo that". Every change is saved as its own version.
- No passwords or keys are stored here. The Web3Forms key in content.json is a public, send-only key by design.
